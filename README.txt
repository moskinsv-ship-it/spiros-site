ВАЖНО:
При открытии index.html двойным кликом внешний вид и логика квиза работают, но PHP-отправка формы невозможна через file://.
Для проверки отправки нужен PHP-сервер/хостинг. На обычном PHP-хостинге загрузите содержимое папки в корень домена.

Основной получатель заявок: spiros@yandex.ru
Если на хостинге функция PHP mail() отключена, заявка всё равно сохраняется в storage/leads-YYYY-MM.jsonl. Папка storage закрыта от веб-доступа через .htaccess.
